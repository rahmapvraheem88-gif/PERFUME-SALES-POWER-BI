Power BI dashboard analyzing perfume sales, customer segments, branches, brands, payment methods, and overall sales performance.

# Perfume Sales Analysis

## Overview
A Power BI dashboard project focused on analyzing perfume sales and customer purchasing patterns.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Data Cleaning
- Checked duplicate Transaction IDs.
- Checked missing and blank values.
- Validated data types and numerical values.
- Cleaned and transformed data using Power Query.
- Verified sales, quantity, and discount data.

## Dashboard
- Total Sales and Orders
- Average Order Value
- Quantity Analysis
- Brand-wise Sales
- Branch-wise Sales
- Customer Type Analysis
- Payment Method Analysis
- Top N Analysis

## Key Insights
- Overall sales and order performance were analyzed.
- Average Order Value was used to understand customer spending.
- Brand-wise analysis helped identify top-performing brands.
- Branch-wise analysis highlighted sales differences.
- Customer types were compared to understand purchasing patterns.
- Payment methods were analyzed to identify customer preferences.
